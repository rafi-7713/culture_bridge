# 🎓 HIT-CultureBridge (哈工大文化桥)

An interactive web application designed to help international students at the Harbin Institute of Technology (HIT) master essential Chinese vocabulary and adapt to campus culture.

## 🚀 Live Demo
- **Web App:** (https://culturebridge-jvsckh7zcsk2vqjpcvx26n.streamlit.app/)
## ✨ Features
- **Interactive Flashcards:** Filter words by HSK level or campus-specific categories with instant reveal mechanisms.
- **Culture & Campus Quiz:** Test knowledge on Harbin traditions, HIT history, and Chinese festivals with immediate feedback.
- **Cross-Platform:** Lightweight, responsive design accessible on mobile and desktop browsers.

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** Streamlit
- **Data Handling:** Pandas
- **Deployment:** Streamlit Community Cloud
